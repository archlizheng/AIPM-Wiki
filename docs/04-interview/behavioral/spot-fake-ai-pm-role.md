# 如何判断一个 AI PM offer 是不是「伪 AI 岗」？

**难度**:⭐⭐ 常规
**出现频率**:中,转行者 / offer 决策场景常见;也常见于「你怎么选岗位」类行为面

## 考察点

- 是否分得清「应用型 AI PM」与「挂羊头卖狗肉」——不把调 API 一律判假
- 能否给出**可验证**的判断信号(职责、评测、拍板权),而不是凭公司名气或 JD 形容词
- 是否体现职业规划意识:入职后能不能攒下可深挖的 AI 决策履历

## 参考答案

### 一句话核心

伪 AI 岗的判据不是「有没有自研模型」,而是:**标题承诺你对 AI 产品结果负责,实际只让你画原型、写文档、催排期**——碰不到效果标准、方案取舍和迭代闭环。

### 先划界:什么不算伪岗

| 情况 | 怎么看 |
|------|--------|
| 应用型(智能客服 / 导购 / 办公助手等,多半调 API) | **通常是真岗**,也是岗位数量最多的一类 |
| 早期团队,评测与监控还不成熟 | 若对方说清「缺什么、授权你建什么」→ 可能是机会;若把「还没有」说成「不需要」→ 谨慎 |
| 标题叫 AI PM,但 JD / 面试都说明是传统功能 + 偶尔对接供应商 | 可以接,但按**传统 PM + AI 素养**定价,别按模型产品负责人规划路径 |

**分界一句话**:真岗至少有一块你长期负责的「模型相关质量」(评测怎么定、错了怎么办、下次改什么);伪岗往往只负责「功能有没有按时上线」。

### 判断框架:三层信号叠加

单一信号不够判死刑;下面三层**叠加出现**时,伪岗概率上升。

**1. JD 层(可读预警)**

- 形容词多、可交付物少:满篇「引领大模型落地」,几乎不写评测、Badcase、灰度、成本、兜底
- 职责像传统交付 PM:排期 / 周报 / 对接外包占比很高,「效果验收」一笔带过
- 成功指标只有上线节点,没有效果、接管率、成本或风险指标的位置
- 编制里没有算法 / 数据 / 评估相关角色,却要求你「主导模型能力」

反向也成立:JD 看起来朴素,但写清「共背效果、参与评测门槛、设计失败兜底」,往往更靠谱。

**2. 面试反问层(主战场)**

带走 4–6 个硬问题,听对方用**事实**还是**愿景**回答:

| 优先问 | 你在听什么 |
|--------|------------|
| 评测集 / 验收标准谁维护?PM 能否参与门槛定义? | 有没有效果所有权 |
| 最近一次因效果不达标延期或回滚,依据是什么? | 有没有真实质量门禁 |
| 模型 / 供应商 / RAG vs 微调,PM 的输入是什么?谁拍板? | 你是文档员还是取舍方 |
| 举近一两月例子:PM 做了哪些不可替代的判断? | 若只剩写 PRD、跟进度 → 职责可能被掏空 |
| 入职 90 天,成功 / 失败各长什么样? | 目标是否可验证 |

面试后对每个答案标三档:**清晰**(有责任人 / 实例 / 指标)、**早期但诚实**(承认不足 + 建设计划 + 你的权限)、**回避 / 空话**。经验规则:效果类问题两题以上空话,且说不清你的判断权 → 更接近交付型挂名。

**3. Offer 前保护**

- 书面确认:你是否至少负责效果标准 / 评测参与 / 方案取舍中的一项
- 对照能力模型自检:未来 12 个月能否练到「数据与评估」「技术认知」;练不到则转型收益会被摊薄
- 想清楚履历:哪怕业务早期,也要能留下评测草稿、Badcase 归因或一次有证据的方案取舍——否则下轮面试很难讲清「我做了什么判断」

### 避坑:常见误判

| 误判 | 更稳妥的看法 |
|------|----------------|
| 「调 API = 假 AI」 | 应用型主流就是调 API;关键看有无场景 / 效果 / 成本 / 兜底决策 |
| 「大厂标题 = 真岗」 | 同一集团不同业务线差异极大;仍要用反问验证具体团队 |
| 「没评测 = 一定是坑」 | 可能是授权你从 0 建;区分「让你建」与「永远不打算建」 |
| 「反问会得罪人」 | 专业团队通常欢迎具体问题;反感硬问题本身也是信号 |

### 回答收束

> 我会先排除「应用型 / 早期建设」这些正常形态,再用 JD 信号 + 面试反问 + Offer 书面职责三层叠加判断。核心只问一件事:**入职后我能不能对一块 AI 相关质量负责,并留下可复述的决策链**。标题再炫、公司再响,若只剩排期和文档,对我这种转型候选人来说机会成本太高。

## 追问延伸

- **追问 1**:「你怎么区分『早期没评测』和『伪岗』?」
  → 关键看对方是否承认缺口、是否给出建设计划和你的权限边界;「清晰地承认没有」可接受,「假装已经有 / 说不需要」要警惕。
- **追问 2**:「如果 Offer 待遇很好但职责偏交付,你接不接?」
  → 先说取舍标准:若 12 个月内仍碰不到效果与方案取舍,转型履历会被摊薄;可以接,但要下调预期(传统 PM + AI 素养),并争取书面划清可练的一块能力。
- **追问 3**:「你反问这些问题,不怕面试官觉得你挑剔吗?」
  → 强调这是双向匹配:你在确认能否创造对方要的结果,也在确认自己能否积累可迁移能力;反感具体问题本身就是组织信号。
