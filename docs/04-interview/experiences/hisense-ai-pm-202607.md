# 海信集团 AI 产品 校招面经

**来源**: 牛客 @我是一个粉刷匠粉刷本领强, 2026-06 | **岗位**: AI 产品 | **类型**: 校招（27 届）

**来源性质**：牛客社区公开面经（部分为社区整理），本文仅整理原文明确内容，未对经历进行独立核验；未披露信息统一标注“原文未披露”。
**背景**：27 届校招生，其他背景原文未披露
**渠道**：原文未披露
**结果**：原文未披露

## 流程概览

简历筛选 → 一面（三位面试官，约 30 分钟，偏 AI 概念与场景设计）→ 二面（HR + Team Leader，约 30 分钟，偏通用 PM 能力与项目深挖）

## 各轮详情

### 一面

**问题清单**:

1. 自我介绍（限时约两分钟）
2. 讲一下 Agent / Workflow / Function Calling / Skill
3. 讲一下幻觉问题
4. 除了幻觉，对于企业来说，AI 还有哪些明显缺陷
5. 讲一下常用的大模型适用的场景
6. 让你搞一个面向海外的营销工具，咋设计
7. 如何处理用于营销的各种数据
8. 产品经理和 AI 产品经理的区别

**一面反问**:

- 做哪方面的软件（投稿者理解偏内部基础架构支持）

**参考回答思路**:

- **Agent 概念族**: Workflow 是固定流程编排；Agent 具备规划与工具调用；Function Calling 是模型调工具的接口层；MCP 是连接外部系统的开放协议；Skill 是可按需加载的程序性知识包(操作手册)——用一张「用户请求如何被拆解执行」的链路串起来。详见 [MCP](../../01-ai-basics/llm/mcp.md) 与 [Agent Skills](../../01-ai-basics/llm/agent-skills.md)。
- **企业侧 AI 缺陷**: 除幻觉外可谈成本不可控、延迟、合规与数据安全、可解释性、冷启动、集成复杂度、组织变革阻力等，每条配一个产品缓解思路。
- **海外营销工具**: 目标市场与用户 → 多语言/本地化 → 内容生成 + 投放 + 效果归因 → 合规（GDPR、广告政策）→ MVP 与指标（CTR、转化、CAC）。
- **营销数据**: 采集（一方/三方数据）→ 清洗与标签 → 隐私合规 → 特征用于个性化与 A/B；强调数据质量对 AI 输出上限的影响。
- **AI PM vs PM**: 在需求定义、验收标准（概率性输出）、与算法协作、评测与迭代节奏上的差异。

### 二面

**问题清单**:

1. 自我介绍
2. 认为产品经理具备什么样的能力
3. 产品经理如何去设计需求，如何跨部门沟通
4. 询问之前的 AI 项目细节
5. 之前的实习，带教对你如何评价
6. 对某段实习进行提问：在这个过程中最大的收获是什么
7. 你认为你符合产品经理这个岗位的一些特质

**二面反问**:

1. 提前这么早校招是有什么特别的需求吗
2. 对新入职的校招生有什么样的预期
3. 是已经在迭代的产品还是从 0 起步的产品

*原帖注明：TL 追问很深，不止上述问题。*

**参考回答思路**:

- **能力与特质**: 用 2–3 个能力（用户洞察、结构化表达、推动力）各配一个实习实例，避免形容词堆砌。
- **需求与跨部门**: 需求来源 → 优先级框架 → PRD/评审 → 研发测试上线 → 复盘；跨部门用共同目标、书面对齐、里程碑与风险预案。
- **项目细节**: STAR 结构，突出个人决策点与可量化结果；AI 项目补充评测与迭代闭环。

## 总结与建议

- 海信校招 AI 产品一面偏「AI 素养 + 开放场景」，二面回归经典 PM 能力与实习深度，两轮风格差异大，需分别准备。
- Agent/Workflow 等概念题建议画一张简单架构图辅助口述。
- 海外营销题可提前准备一个「出海 SaaS 营销 Copilot」的 5 分钟方案练手。
