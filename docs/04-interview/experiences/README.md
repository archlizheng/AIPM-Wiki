# 真实面经

按公司归档的一手面试经历。投稿请使用 [面经模板](../../../templates/interview-experience.md)。

> **说明**: 以下部分内容为社区二手整理（牛客等），仅供备考参考，不代表招聘方官方题库；面试题目与流程可能随批次变化。

## 投稿须知

- 只收**一手经历**(本人或经本人授权),注明面试时间(精确到月)和岗位方向
- 对事实负责,不泄露公司机密(如未公开的产品计划),不进行人身评价
- 文件命名:`公司拼音-岗位方向-YYYYMM.md`,如 `bytedance-llm-app-202607.md`
