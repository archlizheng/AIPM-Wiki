## 各轮详情

### 业务面

**问题清单**:

1. 请你做一个简单自我介绍
2. 你可以详细地介绍一下你是怎么做 AI 视频剪辑的
3. 可以再详细一点吗？
4. 你可以举一个案例吗？它的目的是什么？
5. 你们怎么选脚本的？怎么开始改进的？怎么通过分镜选视频的？以及怎么去配音的？
6. 你的任务目标是干什么？你们怎么开始选（脚本）的？
7. 你们（作为卖英国火车票的平台）怎么生产这个（引流）素材？
8. 你要决定生产什么样的内容才能让他们愿意去买英国火车票，想听一听你这个过程中是怎么选的
9. 你有什么问题问我？

**面试官介绍的岗位信息**（非考题，供理解业务）:

- **产品形态**: 在 App 内做社区 KOL（意见领袖）Agent
- **核心能力**:
  - 内容发布：Agent 自主发帖
  - 主动社交：主动找用户聊天、评论
  - 群组管理：作为 AI 群主活跃气氛
  - 服务提供：用户有找人或发帖需求时，主动推荐匹配用户
- **岗位能力要求**（帖中摘录）:
  - AI 技术：熟悉 Agent 平台搭建、大模型引擎、对话模型微调
  - AI 评估：具备对 AI 进行量化评估的能力
- **参考项目**: 即刻开源项目 easykol

*原帖关于岗位能力要求的第 2 点之后内容在采集时截断，详见数据缺失说明。*

**参考回答思路**:

- **视频剪辑链路**: 按「目标（转化/引流）→ 脚本策略 → 分镜与素材匹配 → 配音与字幕 → 发布与数据复盘」逐步展开，每一环讲一个可量化决策。
- **脚本与内容选型**: 说明目标用户、平台算法偏好、爆款脚本结构、A/B 测试或人工规则；体现「为业务指标服务」而非炫技。
- **与 KOL Agent 岗的关联**: 将视频生产经验映射到 Agent 的「自主发帖、社交、推荐」——强调内容策略、用户匹配与效果评估方法论的可迁移性。
- **反问环节**: 可问 Agent  autonomy 边界、安全与风控、核心指标（互动率、转化、违规率）、与社区运营的分工。

## 总结与建议

- 该岗面试高度「简历面」，会对你做过的 AI 内容生产链路逐层剥洋葱，务必准备到执行细节与数据。
- 提前了解 easykol 等社区 Agent 开源方案，有助于理解岗位技术栈与产品形态。
- 字节面经相似度低是社区共识，本帖重在考察「内容 + Agent + 增长」交叉能力，不宜用通用八股代替项目复盘。
