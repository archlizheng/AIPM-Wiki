## 基于岗位方向的备考提示

以下内容是仓库根据“AI Agent 产品经理”岗位方向补充的准备框架，不是原作者披露的面试题：

- **项目深挖**：准备一个能讲清目标、用户、方案、落地过程和结果的数据化项目，重点说明个人贡献，而不是只介绍团队成果。
- **Agent 产品设计**：能够说明任务拆解、工具调用、上下文管理、人工接管和异常兜底等关键环节，并解释为什么这样设计。
- **评估与迭代**：提前准备 Agent 的质量、成功率、任务完成率、延迟、成本和安全性指标，说明如何通过样本集或线上反馈定位问题。
- **跨背景表达**：商科背景并不等于只讲业务。回答时应把业务目标映射到产品机制和技术约束，至少能说清模型能力边界、数据依赖和评估方法。
