## 各轮详情

### 业务面

**面试官背景**：原文未披露。

**问题清单**：原文没有逐题公开题目。摘要明确提示的考察方向如下，不能视为面试原题：

1. 对智谱主要业务方向的了解与复述。
2. 对办公场景中 AI 使用方式的理解和表达。
3. Prompt 的迭代与优化方法。
4. Agent 的搭建思路。

**基于公开摘要的复盘**：

- **先讲业务，再讲技术**：准备智谱相关面试时，应先梳理公司主要业务、目标用户和典型使用场景，再说明自己如何判断 AI 能解决什么问题。不要只停留在模型名词或功能罗列。
- **办公场景要讲完整链路**：可以按“用户任务 → 当前痛点 → AI 介入点 → 结果验证”的顺序表达，说明 AI 节省了什么成本、提升了什么效率，以及哪些环节仍需要人工确认。
- **Prompt 优化要体现迭代过程**：建议准备一个具体案例，交代初始 Prompt 的问题、修改了哪些指令或输入结构、用什么样例评估效果，以及最终如何决定继续迭代或上线。
- **Agent 搭建要说明边界**：回答 Agent 方案时，可以按“目标 → 任务拆解 → 工具调用 → 状态/记忆 → 异常处理 → 效果评估”展开，并明确哪些动作需要人工确认，避免把 Agent 说成简单的聊天机器人。

以上四点是根据原文摘要整理出的备考框架，不是作者公开的逐题答案。

## 总结与建议

- 这篇面经的核心价值在于明确指出了智谱业务面关注的四类能力：业务理解、办公场景落地、Prompt 迭代和 Agent 搭建。
- 业务面前应准备一个能同时覆盖“业务目标、AI 方案、Prompt 调优、效果评估”的完整案例。
