## 各轮详情

### 一面

**问题清单**:

1. Prompt 怎么优化，怎么写的？
2. 音画不同步怎么办？
3. 我们主要做各种 Prompt 优化，旅游 vlog、赛车 vlog（感兴趣 TTS 吗？）

**参考回答思路**:

- **Prompt 优化**: 结构化模板（角色、素材描述、输出格式、负面约束）→ 版本管理与 A/B → 结合 bad case 迭代；视频场景要约束镜头、节奏、风格。
- **音画不同步**: 产品侧定义可接受偏移阈值；工程上对齐时间轴、重采样、分段对齐；严重 case 人工复核或降级模板。
- **TTS 兴趣**: 结合 vlog 口播场景，谈音色、情感、多语言与视频时长的匹配，体现对业务场景的理解。

### 二面

**问题清单**:

4. 为什么要做产品？
5. 音画不同步、偏移怎么办？有没有音频和视频拆开来的方法？
6. 有没有调研过其他的视频识别模型？有没有自己部署过模型，自测过？

**参考回答思路**:

- **动机题**: 从用户价值、创作门槛降低、可规模化的产品杠杆切入，避免空泛「喜欢产品」。
- **音画分离方案**: 阐述「拆分—分别处理—再合成」的 pipeline；说明适用边界（口播 vs 复杂混剪）与成本。
- **模型调研与自测**: 是否部署过、评测集如何构建、对比维度（准确率、延迟、成本）；无亲手经验也需讲清「我会如何 POC」。

### 三面

**问题清单**（帖中已披露部分）:

7. 你在 AI 视频剪辑选择模型的时候，是怎么调研的？调研过哪些模型？有没有想过拆开……（题干截断）
8. 除了内容角度，还有哪些方面？（帖中仅披露题干，完整上下文缺失）

**帖中提及的模型调研框架**（供 Q7 参考回答）:

需求分析 → 市场调研 + 学术调研 → 性能成本评估 → POC → 技术指标评估；并按场景分工（如视频理解用多模态大模型 Video-LLaMA 等），说明「商业 API 够用的场景」与「需微调开源模型的场景」的取舍逻辑。

**参考回答思路**:

- **调研框架**: 先业务需求拆解，再列候选模型矩阵，POC 指标与上线标准前置定义，避免「先选模型再找场景」。
- **Q8 高阶思维**: 除内容外可从成本、延迟、版权合规、创作者工作流、分发与推荐、数据飞轮等维度展开，体现产品大局观。

## 总结与建议

- B 站该岗极偏「视频 AI 实战」，Prompt、音画同步、模型调研是三板斧，纯大模型八股帮助有限。
- 无部署经验者，至少准备一套「假想 POC 方案」：评测集、对比表、上线门槛。
