# AI PM 的 3–5 年：分水岭、常见误判与出路

> 写给谁：已经完成入门 / 转型冲刺，准备在 AI 产品岗位上干满数年、想少走弯路的人。
> 和 [转型指南](transition-guide.md) 的关系：转型文给的是「3 个月能面试」的行动计划；本文接在其后，讨论**入职之后**如何判断自己有没有在积累可迁移能力，以及 3–5 年常见分叉。
> 立场：中立、少励志。下文是**可自检的模式**，不是晋升时间表，也不是「满 N 年必成」承诺。行业岗位定义本身就不统一，同一 title 在不同公司可能差一整层职责。

选题启发自磊叔《关于 AI 产品经理的 100 个问题》Q13 / Q98 / Q100。

## 先对齐尺子：用什么衡量「有没有往上走」

不要用「公司名气涨没涨」「title 变没变」「是否天天聊最新模型」当唯一尺子。更稳的尺子是本库的 [能力模型](ai-pm-capability-model.md) 五个维度，以及你能不能拿出**可复核的交付物**：

| 维度 | 入职初期常见状态 | 3 年左右更有说服力的证据（示例） |
|------|------------------|----------------------------------|
| 技术认知 | 能听懂术语、能跟方案会 | 能独立写出「Prompt / RAG / 微调 / 不该用 AI」取舍记录，并被团队采纳过至少一次 |
| 产品基本功 | 能写 PRD、推排期 | PRD 里写清错误代价、兜底、人工接管条件；对照 [Agentic UX](../02-pm-skills/prd-and-design/agentic-ux-and-trust-calibration.md) 有落地 |
| 数据与评估 | 知道要看效果 | 维护过评测集 / 上线门槛 / Badcase 归因闭环中的至少一块，且能讲清 offline 与线上指标为何会脱节 |
| 商业判断 | 知道 token 会花钱 | 做过一次选型或分级服务的成本—效果—延迟对照，并影响过范围裁剪 |
| 伦理与合规 | 知道有红线 | 在设计阶段就标过风险点与升级路径，而不是上线前突击补材料 |

若你对照后发现：三年里前两维在动、后三维几乎空白，这通常不是「还没开窍」，而是岗位职责或个人投入方向出了问题——先用 [如何识别伪 AI 岗](spot-fake-ai-pm-jobs.md) 排查岗位，再用本文后面的误判清单排查自己。

## 一、大约满 3 年：留下来的人与停滞的人，差在哪

「3 年」不是魔法数字，只是市场上较常出现的复盘窗口：入职时的新鲜感消退，履历开始被下一家认真追问「你真正负责过什么」。公开招聘里，成熟团队会把评测闭环、安全边界、跨研究/工程协作写进 PM 职责（例如 Anthropic 招聘页上的 Safeguards、Model Behaviors、Claude 产品线等方向，截至 2026-08 仍可见），这可以作为**职责完整度**的参照，而不是要求人人都去模型厂商。

更可验证的分水岭，往往是下面三类信号（满足越多，越像「在积累」；长期全缺，越像「在空转」）：

### 1. 效果所有权：你是不是效果标准的一方

- **积累侧**：你参与或主导过「什么叫做成」——评测用例来源、通过门槛、回滚条件、Badcase 怎么回流。面试时能按 [项目深挖](../04-interview/preparation/project-deep-dive.md) 讲清一次失败复盘。
- **空转侧**：成功定义永远在算法或供应商那边；你只负责「功能按时上线」。换公司后，很难证明自己做过 AI 产品判断。

### 2. 决策半径：你留下的是判断记录，还是会议纪要

- **积累侧**：至少有几次可复述的取舍——场景该不该上 AI、用哪条技术路径、成本超了砍哪块体验、合规卡住怎么改产品形态。判断可以错，但要有依据与复盘。
- **空转侧**：三年只剩「对接了多少需求、跟了多少迭代」。title 可能上涨，可迁移的 AI 决策链仍薄。

### 3. 岗位选择：你有没有主动避开「标题通胀」

- **积累侧**：会用 JD / 面试反问筛真岗（见 [伪岗识别](spot-fake-ai-pm-jobs.md)），愿意为「能碰评测与取舍」牺牲一点短期光鲜 title。
- **空转侧**：反复跳到「看起来很 AI、实际很交付」的岗位，履历年份在涨，能力结构不变。

**一句话**：分水岭很少是「谁更懂最新论文」，更多是——三年后你能不能证明自己对**不确定性系统**做过可辩护的产品决策。技术词汇是入场证；评估、成本与合规上的判断，才是后续岗位筛选时更难伪造的部分。

## 二、回头看最常见的误判（可自检，不保证穷尽）

下列误判来自能力模型与岗位形态的推演，以及公开 JD 对「评估 / 安全 / 商业化」职责的反复强调。它们是**模式**，不是统计结论；请用右侧「怎么自证」列做个人核查，而不是对号入座骂自己。

| 误判 | 常见表现 | 怎么自证 / 纠偏 |
|------|----------|-----------------|
| 把「模型品牌」当成护城河 | 大量时间花在追新模型、比榜单；产品差异化说不清 | 问自己：换一个同级模型后，产品还有什么优势？若答案只剩「我们用了 X」，差异化可能在工程、数据、工作流与分发，而不在模型 logo |
| 把演示当产品完成度 | Demo 惊艳就规划大规模推广；上线后才补兜底与长尾 | 对照 [Fallback 与反馈设计](../02-pm-skills/prd-and-design/fallback-and-feedback-design.md)：主路径、失败态、人工接管是否在上线前就有验收标准 |
| 把评估外包给「算法感觉」 | 没有评测集 / 门槛，靠抽查与老板观感迭代 | 对照 [模型评估](../02-pm-skills/model-evaluation/README.md)：你能否独立说出当前版本的必过用例与已知失败模式 |
| 成本后置 | 功能定完才问单价与日调用；免费无限用成为默认承诺 | 用 [LLM 成本入门](../02-pm-skills/cost-and-tech/llm-cost-101.md) 做一版粗算；把成本写成范围裁剪的输入，而不是上线后的惊讶 |
| 合规后置 | 「先跑通再找法务」；C 端生成、未成年人、金融医疗场景尤其危险 | 至少读懂适用的国内生成式 AI 管理要求入口（见文末参考资料），在 PRD 里留风险与升级路径 |
| 用跳槽代替深耕 | 每 8–12 个月换公司，但负责模块始终是「对话壳 + Prompt」 | 连续两份工作之间，评估 / 成本 / 合规三维是否至少有一维明显加深；没有则优先换职责，而不是只换雇主 |

这些误判的共同点：**技术细节通常能补，错误的优先级会烧掉窗口期。** 纠偏动作也尽量可验证——写一页取舍备忘、补一套最小评测、做一次成本对照、约一次合规评审——比「多学一门课」更容易在下一轮面试里被追问出细节。

## 三、大约满 5 年：人常见去哪（模式，非命运）

「5 年 AI PM」同样不是统一人群：有人从 2020 前后的对话式产品做起，有人从传统业务嵌入 AI 功能做起，有人从数据/算法转产品。公开市场能核实的，不是「五年后大家薪水中位数」，而是**职责会分叉**，且成熟组织普遍存在 IC（个人贡献）与管理双通道——Lenny Rachitsky 对多家公司职业阶梯的梳理，以及 Mind the Product 等讨论，都指向「Senior 前后常出现分叉，双通道应对等长」这类结构（见文末参考资料）。具体 title 因公司而异，勿逐字对照。

结合本库 [岗位类型](ai-pm-job-types.md)，五年左右较常见的去向可以粗分为：

| 去向 | 大概在做什么 | 更吃哪类积累 | 自检问题 |
|------|--------------|--------------|----------|
| 应用 / 场景深耕（IC） | 继续做核心场景负责人：效果、体验、成本、迭代节奏 | 评估闭环 + 产品判断 | 我能否不带团队、仅凭判断影响跨组路线图？ |
| 领域 / 平台加宽（IC 或管理） | 从单场景扩到评测平台、推理网关、Agent 平台、行业解决方案 | 技术认知深度 + 商业打包 | 我解决的是「一个功能」还是「一类能力的复用」？ |
| 组织与团队（管理） | 带 PM / 协调算法与业务、定优先级文化与招聘标准 | 协作与人才判断；产品手感仍要在 | 我是否享受培养他人与组织设计？还是只想自己做难问题？ |
| 安全 / 合规 / 信任产品 | 内容安全、滥用防护、高风险场景产品化 | 伦理合规 + 跨法务协作 | 我是否愿意长期处理「低频高损」问题？ |
| 相邻角色 | 创业、行业顾问、投资侧产品判断等 | 可抽象的决策框架 + 踩坑样本 | 我的判断能否迁移到「别人的项目」上，而不只依赖本公司权限？ |

头部实验室与 AI 原生公司的招聘页能侧面印证「分叉已经发生」：同一家公司里，既有消费端 / 企业产品 PM，也有 Research PM、Safeguards PM、开发者与平台向 PM（Anthropic 招聘页截至 2026-08 可见多条并行方向）。这不等于你的五年目标必须是其中某一条，只说明——**继续叫「AI PM」时，要主动选择加深哪条职责轴**，否则容易停在「会做对话功能」的可替代层。

### 选择分叉时，优先问三件事

1. **我还想靠近产品手感吗？** 想：偏 IC / 场景负责人。不想、更想放大他人产出：偏管理（并补招聘、绩效、组织设计，这些不是「资深 PM 自动附赠」）。
2. **我的差异化是行业还是横向方法？** 有医疗 / 教育 / 金融 / 制造等深背景，垂直 AI 往往比再去卷通用大模型岗更顺；横向强的人更适合平台、评测、多业务复用。
3. **下一份工作能否让后三维继续变厚？** 若新机会只加 title、不加评估 / 成本 / 合规职责，五年复盘时仍可能重复三年时的空转。

## 四、每年可执行的复盘（建议直接复制）

把「鸡汤目标」换成可勾选动作。建议每年固定一次（晋升季或跳槽前也可以用）：

1. 对照 [能力模型](ai-pm-capability-model.md) 五维打分；记下最低的 1–2 维。
2. 列出过去 12 个月**你亲自拍板或强影响**的 3 次 AI 相关取舍（含一次失败）。写不清的，说明决策链不在你身上。
3. 检查作品集是否至少更新过一件：评测集片段、成本测算、合规风险清单、逆向 PRD、线上指标复盘——任选其一对下一份工作仍有用。
4. 用 [伪岗清单](spot-fake-ai-pm-jobs.md) 审视当前职责；若连续两个季度碰不到效果标准，优先内部换模块，再考虑换公司。
5. 若已接近 Senior 分叉，用本文第三节表格选一个主方向，**写进下一年 OKR**，避免「什么热门追什么」。
