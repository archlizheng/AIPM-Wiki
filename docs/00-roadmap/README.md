## 三条阅读路线

### 新人入门

按00—05原有顺序： [入门路径](getting-started.md) → [AI 基础](../01-ai-basics/README.md) → [需求发现](../02-pm-skills/prd-and-design/ai-demand-discovery.md) → [AI PRD](../02-pm-skills/prd-and-design/ai-prd-guide.md) → [评测集](../02-pm-skills/model-evaluation/build-your-eval-set.md) → [案例](../03-case-studies/README.md) → [面试题](../04-interview/README.md)。验收是能解释一个问题为何值得用 AI，并提出可检查的完成标准。

### 企业 AI 在岗进阶

先修 Agent、RAG、MCP 与基本 PRD。按 [需求发现](../02-pm-skills/prd-and-design/ai-demand-discovery.md) → [平台与运行时选型](../02-pm-skills/cost-and-tech/agent-platform-selection-and-governance.md) → [生产化](../02-pm-skills/ai-product-operations/agent-product-design.md) → [安全](../02-pm-skills/ai-product-operations/guardrails-and-agent-security.md) → [评测](../02-pm-skills/ai-product-operations/agent-evaluation-and-observability.md) → [指标](../02-pm-skills/ai-product-operations/ai-product-metrics.md) → [成本与定价](../02-pm-skills/cost-and-tech/README.md) → [组织采用](../02-pm-skills/ai-product-operations/poc-to-production-adoption.md)。需要跨会话偏好时加读 [记忆](../02-pm-skills/ai-product-operations/agent-memory-design.md)；按产品形态选读 [文档](../02-pm-skills/prd-and-design/document-intelligence-design.md)、[语音](../02-pm-skills/prd-and-design/realtime-voice-agent-design.md)、[电脑操作](../02-pm-skills/prd-and-design/computer-use-product-design.md)。验收是能提交有责任人、阶段门槛与退出条件的试点方案。

### 内部服务助手实践

先修需求发现与 Agent 入门，再顺序完成 [P1 立项](../02-pm-skills/practice/internal-service-discovery.md) → [P2 PRD](../02-pm-skills/practice/internal-service-prd.md) → [P3 评测](../02-pm-skills/practice/internal-service-evaluation.md) → [P4 成本与采用](../02-pm-skills/practice/internal-service-adoption.md) → [四道原创题](../02-pm-skills/practice/README.md#四道原创练习)。验收是四份文档能共用同一组权限、状态、材料与统计定义；本路线全部为虚构教学推演。
