# ChatGPT 案例拆解

**分类**：对话助手

**资料核验**：2026-09-14；核对公开产品页与退场公告，未进行本轮实机体验。

## 一、产品背景

ChatGPT 将问答、研究与工作任务放在同一产品入口。对 PM 有价值的问题是：用户从“问一下”升级到“交给你办”，产品怎样保持任务边界清楚？本文分析这个转变，不用不同统计窗口的周活、App 月活或 OpenAI 公司收入推算产品盈利。

## 二、核心功能拆解

截至核验日，[官方套餐页](https://chatgpt.com/pricing/)列出聊天、文件、图像、语音、研究和 Codex 等能力，并按档位限制额度。Plus 已列 GPT-6 Astra 与 GPT-5.6；Work 的桌面、网页、移动端权益随套餐不同。模型名称与权益会变化，不能把旧版“免费用户只有聊天”继续当作产品定位。

[Deep research 官方介绍](https://openai.com/index/introducing-deep-research/)呈现的具体链路是用户提出研究问题、提供材料，系统进行多步在线研究并形成带出处的报告。发布页中的原始效果和时长不能直接当作本月所有模型/套餐的承诺；本案例保留“问题→研究→可追溯报告”这一产品链路。

可从三类完成标准理解功能组织。下表是作者的评审框架，不是声称每次实际使用均达标：

| 用户任务 | 可以交给 AI 的部分 | PM 应验收的完成证据 |
|---|---|---|
| 问政策或查资料 | 搜索、提炼、呈现来源 | 引用支持对应结论，时间和适用范围正确 |
| 做研究、写文档 | 整合材料、形成可修改产物 | 文件可打开、事实可回链、待确认项清楚 |
| 修改项目或运行长任务 | 分解任务、调用工具、记录过程 | 最终变更、验证结果、异常和未完成项 |

一个教学评审任务可以是“用三份材料写部门设备更新建议”。先给出预算与来源范围；第一轮检查是否主动识别缺失条件；第二轮检查引用和表格公式；第三轮要求修改一个假设，看产物能否同步修改。只凭第一次生成了一页漂亮摘要，无法验证持续协作。

长任务还需要分清“模型仍在思考”“等待用户确认”“工具已发出但结果未知”。后台通知应带回任务和产物的位置，用户说取消后应说明停止了哪一部分。具体设计见 [Agent 产品生产化](../../02-pm-skills/ai-product-operations/agent-product-design.md)。

### 产品退场也是产品设计

[官方 Sora 退场说明](https://help.openai.com/en/articles/20001152-what-to-know-about-the-sora-discontinuation)明确：网页和 App 已于 **2026-04-26** 停止，API 计划于 **2026-09-24** 停止。因此在 9 月 14 日应写“API 即将停止”，不能写“已全部关停”，也不能继续把 Sora 列为当前订阅卖点。本文不根据退场倒推亏损规模或内部战略动机。

PM 可借鉴的是迁移要求：列出受影响入口、最后可用日、产物导出、余额处理和替代流程，分别通知用户。停一个入口不等于另一个入口同时停止。

## 三、技术方案推测

公开产品页面能证明功能入口，不能证明完整后台实现。若设计类似产品，通常需要任务状态、工具权限、来源管理与产物存储；这是作者提出的设计需求。不能据此断言 ChatGPT 每个模式采用某种路由、特定模型或固定多 Agent 架构。

API 模型上下文、ChatGPT 套餐上下文和单次文件上传限制也是不同对象，统一到 [模型盘点](../../01-ai-basics/llm/model-landscape.md)及具体产品帮助页核对。

## 四、商业模式

可观察的结构是个人分层订阅与组织套餐；模型 API 为另一产品与账单。当前定价页的数值价格存在地区和动态展示差异，本次不保留无法完整核验的企业席位估价。采购应保存地区、币种、账期、税费、额度和适用入口，而非只记一个月费。

套餐页还说明 Go 可能包含广告。这仅支持对应套餐的产品事实，不证明广告已盈利，也不证明 Shopping Research 的自然推荐都是付费广告。订阅、广告、交易与 API 的讨论见 [商业化路径](assistant-monetization-paths.md)。

## 五、PM 视角的启示

1. **用完成标准区分入口。** 答案要核验来源，文件要可编辑，代码变更要有验证；不能用同一“回复满意度”覆盖所有任务。
2. **统一入口需要清晰的限制说明。** 同一账号能看到功能，不代表所在套餐有相同额度或后台执行条件。
3. **把退场纳入生命周期。** 对用户来说，导出旧资产和替代工作流与新功能同样重要。
