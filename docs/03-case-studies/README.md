# 03 · AI 应用案例拆解

通过拆解真实产品建立 sense:它解决什么问题?技术方案大概是什么?怎么赚钱?有什么可借鉴的?

所有案例遵循统一模板:[templates/case-study.md](../../templates/case-study.md)。

## 目录

- [chatbot-assistant/](chatbot-assistant/README.md) —— 对话助手类(ChatGPT、豆包、Kimi…)
- [aigc/](aigc/README.md) —— 内容生成类(文生图、视频、音频、代码)
- [search-and-rec/](search-and-rec/README.md) —— 搜索与推荐(AI 搜索、个性化推荐)
- [vertical/](vertical/README.md) —— 垂直行业(医疗、教育、法律、电商客服…)

## 怎么用这个板块

不要只看结论。建议先自己上手体验产品 → 自己写拆解 → 再对照案例找差距。面试中的产品分析题,考的就是这个过程的熟练度。

## 进阶与实践衔接

- [Google Workspace Agent 工作流](chatbot-assistant/google-workspace-agents.md)：先修文档智能与 Agentic UX；关注跨应用交接、可编辑产物、审核发送和可用范围。
- [Docusign 合同 Agent](vertical/docusign-contract-agents.md)：先修企业采用与平台选型；关注合同工作流责任和公司披露边界。
