# 信息源：Newsletter、博客、播客

> AI 行业变化快，好的信息源比囤课更重要。每个条目附一句话说明「它好在哪」。  
> 截至 2026-09，本页优先收录仍稳定更新、可持续跟读的来源；单条能力仍需回到产品公告或文档核验状态。

## Newsletter

- [Lenny's Newsletter](https://www.lennysnewsletter.com/)：AI PM 访谈、岗位趋势和实战框架兼具，信息密度很高。
- [Stratechery](https://stratechery.com/)：用商业战略视角解释科技变化，适合做中长期判断。
- [One Useful Thing](https://www.oneusefulthing.org/)：Ethan Mollick 持续讨论 AI 对工作方式和组织协作的真实影响。
- [The Batch](https://www.deeplearning.ai/the-batch/)：DeepLearning.AI 周报，适合快速扫行业动态与新工具。
- [Import AI](https://importai.substack.com/)：研究导向强，适合需要跟踪前沿论文与模型进展的 PM。
- [Latent Space / AINews](https://www.latent.space/)：工程实践与开发者生态信息丰富，适合技术型 PM。
- [TLDR AI](https://tldr.tech/ai)：工作日快讯风格，适合低成本保持更新频率。
- [歸藏 guizang.ai](https://www.guizang.ai/)：中文世界里相对稳定的产品与工具深度解读来源。

## 博客 / 专栏

- [Anthropic Research](https://www.anthropic.com/research)：模型能力、安全与产品化边界的一手信息源。
- [OpenAI News](https://openai.com/news/)：官方发布和工程更新集中，适合追踪产品能力变化。
- [Google AI Blog](https://blog.google/technology/ai/)：Google 体系内研究与产品推进节奏的窗口。
- [Simon Willison's Weblog](https://simonwillison.net/)：LLM 工程与工具实践拆解非常及时、可复用。
- [The Pragmatic Engineer](https://newsletter.pragmaticengineer.com/)：从工程组织与商业现实视角看 AI 变革。
- [Interconnects](https://www.interconnects.ai/)：偏研究趋势与模型方向，适合做战略层补充阅读。
- [Eugene Yan](https://eugeneyan.com/)：机器学习产品化方法与案例文章质量稳定。
- [歸藏 guizang.ai](https://www.guizang.ai/)：中文案例、产品分析与工具实践内容较系统。

## 官方白皮书 / 指南（Agent 方向）

- [Building Effective AI Agents（Anthropic）](https://www.anthropic.com/engineering/building-effective-agents)：最常被引用的 Agent 方法论长文，强调先简单后复杂。
- [Effective Context Engineering for AI Agents（Anthropic）](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)：专讲上下文工程，适合解决长任务与多步骤不稳定问题。
- [Demystifying evals for AI agents（Anthropic）](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)：讲如何把 Agent 评估从“感觉”变成可回归的测试体系。
- [Building agents（OpenAI）](https://developers.openai.com/tracks/building-agents)：OpenAI 官方学习路径，覆盖 tools、orchestration、guardrails 和 tracing。
- [A practical guide to building agents（OpenAI）](https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/)：偏产品与工程落地的实践指南，适合 PM 和技术负责人共读。
- [A practical guide to building agents（PDF）](https://cdn.openai.com/business-guides-and-resources/a-practical-guide-to-building-agents.pdf)：同名白皮书 PDF 版本，便于离线阅读和团队分享。
- [An enterprise guide to multi-agent systems（Google Cloud）](https://cloud.google.com/resources/content/enterprise-guide-ai-agents)：Google 官方多 Agent 企业指南，重点在生产化与治理。
- [The AI agent handbook（Google Cloud）](https://cloud.google.com/resources/content/ai-agent-handbook)：Google 官方业务向手册，适合非技术 stakeholder 快速建立共识。

## 本轮专题跟踪入口

- [GPT-Live-1 in the API](https://openai.com/index/introducing-gpt-live-1-in-the-api/)：2026-09-10 官方公告，跟踪实时语音 API 的可用范围、打断和后台委派。
- [Workspace agentic capabilities](https://workspace.google.com/blog/product-announcements/less-switching-more-flow-5-new-agentic-capabilities-across-google-workspace-apps)：2026-09-09 官方公告，跟踪跨应用可编辑交付物和滚动开放范围。
- [GitHub Copilot weekly releases](https://github.blog/changelog/2026-09-10-github-copilot-weekly-releases-september-7/)：2026-09-10 官方 Changelog，逐项标注 Experimental 和 Public Preview。
- [Qwen-UI-Agent](https://arxiv.org/abs/2607.28227) 与 [Qwen-Image-Agent](https://arxiv.org/abs/2606.26907)：原始论文入口，适合观察 GUI 与图像 Agent 研究方向，不能据此推断 GA 产品。

## 播客

- [Lenny's Podcast](https://www.lennysnewsletter.com/s/podcast)：AI 与产品负责人访谈质量高，适合通勤学习。
- [Hard Fork](https://www.nytimes.com/column/hard-fork)：媒体视角覆盖政策、公司与产品，信息面广。
- [Pragmatic Engineer Podcast](https://www.pragmaticengineer.com/podcast)：偏工程管理与 AI 组织实践，适合团队负责人。
- [Latent Space](https://www.latent.space/podcast)：开发者生态和工具演进解读及时，适合技术协作型 PM。
- [张小珺Jùn｜商业访谈录](https://www.xiaoyuzhoufm.com/podcast/626b46ea9cbbf0451cf5a962)：中文深度访谈标杆，2–7 小时长对话，一线从业者信息密度极高。
- [硅谷101](https://www.xiaoyuzhoufm.com/podcast/5e5c52c9418a84a04625e6cc)：硅谷视角的科技商业播客，AI、芯片、资本与产业趋势覆盖全面。
- [AI产品进化论](https://www.xiaoyuzhoufm.com/podcast/68bf910d723c5fe564fc6972)：两位大厂 AI PM 主理，偏实战与职业发展，适合同行交流。
- [十字路口Crossing](https://www.xiaoyuzhoufm.com/podcast/60502e253c92d4f62c2a9577)：关注 AI 创业与行业变化，宏观判断与一线创业者视角兼具。

## 不建议作为持续跟踪源

- 产品沉思录：已完结，适合当历史资料，不适合做持续信息输入。
- AI产品观察：近期更新不稳定，不建议放入主跟踪列表。
- 人民公园说AI：可听观点，但导流属性较强，建议作为备选而非主榜。
