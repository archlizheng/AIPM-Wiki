# 课程与视频

> 优先收录免费、系统的课程。付费课程需注明价格，禁止软广。  
> 截至 2026-07，主榜以官方课程与高校公开课为主。

## 免费课程

- [AI Prompting for Everyone](https://www.deeplearning.ai/courses/ai-prompting-for-everyone)（DeepLearning.AI）：最适合 PM 的 Prompt 入门课，覆盖检索、写作和多模态协作。
- [Agentic AI](https://www.deeplearning.ai/courses/agentic-ai)（DeepLearning.AI）：系统讲 Reflection、Tool Use、Planning、Multi-Agent 四类模式。
- [Agent Skills with Anthropic](https://www.deeplearning.ai/courses/agent-skills-with-anthropic)（DeepLearning.AI × Anthropic）：直接对应 Skills 工作流，和本站 `agent-skills.md` 互补。
- [MCP: Build Rich-Context AI Apps with Anthropic](https://www.deeplearning.ai/courses/mcp-build-rich-context-ai-apps-with-anthropic)（DeepLearning.AI × Anthropic）：理解 MCP 连接层的高性价比入门课。
- [ChatGPT Prompt Engineering for Developers](https://www.deeplearning.ai/courses/chatgpt-prompt-eng)（DeepLearning.AI × OpenAI）：经典短课，适合有 API 协作需求的 PM。
- [Multi AI Agent Systems with crewAI](https://www.deeplearning.ai/courses/multi-ai-agent-systems-with-crewai)（DeepLearning.AI × crewAI）：用商业流程案例讲多 Agent 编排，贴近业务落地。
- [Anthropic Academy](https://anthropic.skilljar.com/)（Anthropic）：Claude、MCP、Skills 官方课程矩阵，适合做体系化补课。
- [Prompt Engineering Interactive Tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial)（Anthropic）：9 章交互式练习，适合做 Prompt 基础训练。
- [OpenAI Academy](https://academy.openai.com/)（OpenAI）：按 Foundations→Applied→Agents 组织，便于按项目阶段补齐能力。
- [AI Agents Course](https://huggingface.co/learn/agents-course/) / [LLM Course](https://huggingface.co/learn/llm-course/)（Hugging Face）：开源生态视角完整，适合技术型 PM。
- [生成式 AI 简介](https://www.skills.google/course_templates/536)（Google Skills）：45 分钟微课，适合零基础快速建立共同语言。

> 说明：DeepLearning.AI 多数课程可免费学习，证书/进阶能力通常为可选付费，请以官网当期说明为准。

## 视频频道

- [3Blue1Brown](https://www.youtube.com/@3blue1brown)（重点看 *But what is a GPT?*）：用可视化讲清 Transformer 直觉。
- [李宏毅 Hung-yi Lee](https://www.youtube.com/@HUNG-YILEE)：中文公开课体系完整，2025 系列仍值得按课学习。
- [OpenBMB 清华大模型公开课 S2](https://www.bilibili.com/video/BV1pf421z757)：中文官方公开课，技术深度与可学性平衡较好。
- [Stanford Online](https://www.youtube.com/@stanfordonline)：可按主题选看 LLM/Agent 相关课程录像，不必整套跟完。
- [DeepLearningAI 频道](https://www.youtube.com/@Deeplearningai)：作为短课补充资料库，适合查漏补缺。

## 谨慎收录

- Coursera 的 AI PM 证书课（Google/Microsoft/IBM）：体系化不错，但与主榜免费内容重合较高，建议按证书需求再选。
- B 站「7 天就业」「内部课泄露」类视频：标题党和引流特征明显，不建议纳入本页主榜。
