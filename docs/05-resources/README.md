# 05 · 资源导航

经过筛选的学习资源。收录标准:自己看过、确实有用、附一句话推荐理由。

## 目录

- [books.md](books.md) —— 书籍
- [courses.md](courses.md) —— 课程与视频
- [newsletters-and-blogs.md](newsletters-and-blogs.md) —— 信息源:Newsletter、博客、播客
- [tools.md](tools.md) —— 值得上手的 AI 工具与平台

## 收录原则

宁缺毋滥。每类资源控制在 10-20 个以内,超过则淘汰旧的——资源列表的价值在于筛选,不在于堆砌。

## 按任务找资源

- **入门**：配合 [基础路线](../00-roadmap/README.md#新人入门)选课程，先理解任务、模型和评测。
- **进阶**：从 [平台选型](../02-pm-skills/cost-and-tech/agent-platform-selection-and-governance.md)及 [文档/语音/电脑操作](../02-pm-skills/prd-and-design/README.md)正文的官方来源进入；核对版本与发布状态。
- **实践**：先完成 [内部服务助手四课](../02-pm-skills/practice/README.md)，再按缺口查工具和课程，避免只扩收藏清单。
